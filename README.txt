FUZZYBEE GARDEN CARE — WEBSITE RELEASE

Upload the CONTENTS of this ZIP to the publishing root of your existing Fuzzybee GitHub Pages repository (the directory that already contains index.html). Keep the images folder intact. Do not upload the ZIP itself or enclose the files in an extra folder.

1. Back up the existing repository or retain its current commit.
2. Extract this ZIP in Files on your iPad.
3. Upload index.html, wreaths.html, style.css, site.js and the images folder into the existing publishing root, preserving the exact names and paths. If the GitHub web uploader will not upload a folder, create/upload the images directory and files separately, or use Git.
4. Commit your changes. Check your existing GitHub Pages settings and publishing source; do not change them unnecessarily.
5. Visit https://fuzzybee-uk.github.io/Fuzzybee/ and check the homepage, wreaths, navigation, images and contact links on a phone and a tablet.

The design and copy come from your approved uploaded HTML. The original PNG logo is unchanged. JPEG photographs have been converted to WebP at their existing dimensions, with one repeated wreath photo shared between pages. The original three wreath examples are retained; there is no bespoke ordering or online checkout. The original pricing text (£30 and free local delivery in Denmead, subject to confirmation) has been retained; confirm it before publication. No live repository changes have been made.

The site does not require a build system, external image host or third-party libraries. The small site.js file expands the services list and forwards old #wreaths links.
